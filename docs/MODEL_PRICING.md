# قیمت مدل‌ها (اعتبار ACA)

واحد **اعتبار ACA**: برای هر مدل هزینه = `(توکن ورودی / 1_000_000 × نرخ ورودی) + (توکن خروجی / 1_000_000 × نرخ خروجی)`.

نرخ‌ها در `agent/model_catalog.py` تعریف شده‌اند (بر اساس USD/1M توکن × 1000). API: `GET /api/billing/models/`

| مدل | ورودی / 1M توکن (اعتبار) | خروجی / 1M توکن (اعتبار) |
|-----|---------------------------|---------------------------|
| gpt-4o-mini | 150 | 600 |
| gpt-4o | 2500 | 10000 |
| gpt-4.1-mini | 400 | 1600 |
| gpt-4.1 | 2000 | 8000 |
| o3-mini | 1100 | 4400 |
| o1-mini | 1100 | 4400 |
| deepseek-chat | 140 | 280 |
| gemini-2.0-flash | 100 | 400 |

## شارژ حساب

1. کاربر Django بسازید (`createsuperuser` یا admin → Users).
2. Admin → **کیف پول‌ها** → انتخاب کاربر → action **«شارژ ۱۰۰۰۰ اعتبار»**.

## محاسبه مصرف

- اولویت با `usage` برگشتی از API گپ‌جی‌پی‌تی (OpenAI-compatible).
- اگر `usage` نبود: برآورد از طول متن (هر ~۴ کاراکتر ≈ ۱ توکن) و علامت `estimated` در رکورد مصرف.

      API شخصی (مدل)

      کلید خودتان را وارد کنید تا در انتخاب مدل composer، گزینهٔ «API شخصی» فعال شود. در این حالت هزینه از اعتبار ACA کسر نمی‌شود و درخواست‌ها مستقیماً با کلید شما به ارائه‌دهنده ارسال می‌شوند.

      کلید ذخیره‌شده روی سرور رمزنگاری می‌شود و در UI نمایش داده نمی‌شود.

      مدل‌های composer

      مدل‌هایی که در باکس انتخاب مدل چت نمایش داده می‌شوند را تیک بزنید. قیمت‌ها فقط در این لیست نشان داده می‌شوند.

      لاگ و عیب‌یابی

      همان «نمایش بیشتر» در پنل phase-log است.

      راهنمای ACA (ویکی)

      ACA یک دستیار ساده برای نوشتن، اجرا و نگهداری پروژه است. کار اصلی کدنویسی است؛ زمان‌بندی، اتصال به سرور، مارکتینگ و دیباگ از طریق منابع توسط ایجنت ساخته می‌شوند — نه پنل جدا.

      تگ‌های منابع

      • زمان (time) — اجرای کار در تاریخ/ساعت مشخص یا تکرارشونده.
      • اتصال (connection) — SSH، اینستاگرام، API و هر سرویس خارجی.
      • گردش‌کار (workflow) — زنجیرهٔ چند منبع (مثلاً زمان → خبر → استوری).
      • هوش مصنوعی (ai) — جستجو و تولید محتوا.
      • دیباگ (debug) — تحلیل خطا و اسکن صفحه.
      • عملیات (ops) — nginx، deploy و کار روی سرور.
      • دانش (knowledge) — متن و راهنما بدون اجرا.

      نمونهٔ درخواست‌ها

      «به سرور وصل شو و nginx را تنظیم کن» — ایجنت منبع اتصال SSH می‌سازد، تست می‌گیرد، بعد دستورات شما را اجرا می‌کند.
      «هر شب ساعت ۲۱ استوری خبر بگذار» — منبع اتصال اینستا + منبع زمان + منبع تولید محتوا.

      منابع هر مکالمه در پنل «منابع مکالمه» دیده می‌شوند؛ ساخت و ویرایش فقط توسط ایجنت است.
